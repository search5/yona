# P3-45: 템플릿을 Tailwind CSS + htmx 기반으로 리팩터링 (2026-09-10 사용자 제안)

## 배경

`docs/TEMPLATE_BACKLOG.md`(legacy → Thymeleaf 이식, 242/242 완료)로 기능적 동치성은 확보됐지만,
현재 화면은 여전히 **Bootstrap 2.3.1**(2012년 릴리스) + **jQuery 3.3.1** 기반 마크업/스타일/상호작용을
그대로 쓰고 있다. 사용자가 별도 리모트(`search5/yona`, `git@github.com:search5/yona.git`)를 가리키는
`tailwindcss` 브랜치를 만들고, 이 기술 스택을 Tailwind CSS(유틸리티 우선 CSS) + htmx(선언적 부분
페이지 갱신)로 교체하는 리팩터링을 지시했다.

**"리팩터링"의 범위 해석(설계 결정)**: 화면의 정보구조·기능·필드는 바꾸지 않는다(TEMPLATE_BACKLOG의
"이식식 독자 구현 금지" 원칙과 동일 정신 — 이번엔 "legacy 대조" 대신 "현재 yona 화면 대조"). 바뀌는 것은
마크업/CSS 클래스 체계(Bootstrap → Tailwind 유틸리티)와 서버 왕복형 상호작용의 구현 방식(jQuery
`$.ajax`/수동 DOM 조작 → htmx 속성)뿐이다. 시각적 재디자인이 필요하면 별도로 명시적 지시를 받는다.
